# Selina Lavery: Developer Portfolio

My personal portfolio site, built with React and deployed to GitHub Pages.

**Live site:** [selinalaverydev.github.io/selina-dev-portfolio](https://selinalaverydev.github.io/selina-dev-portfolio/)

**Tech:** React · JavaScript · CSS · GitHub Pages

## Run it locally

```
npm install
npm start
```

Then open http://localhost:3000.

> A redesign is planned. The current version is from 2023.
